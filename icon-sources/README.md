# Icon sources

Icons the user supplied, kept in the repository for use when a look needs one. They are not bundled in the app as they are: the ones in use are copied
(to `app/src/main/assets/icons/<look>/<key>.webp`, one key per icon, see `MAP.txt` there).

- `windows-7/NNN.webp` - Windows 7 icons, 64 x 64.
- `windows-vista/<Group><NNN>.webp` - Windows Vista icons (identical pictures removed), 64 x 64.
- `msn-messenger/` - MSN Messenger emoticons (classic and redrawn), as supplied.

All the icons were shrunk to one size (64 px): no icon is bigger than another. The licence of the originals is not stated.
