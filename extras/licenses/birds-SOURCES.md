# Bird pack sources

All recordings are from Wikimedia Commons (mostly originally from xeno-canto). Each loop is a processed excerpt (high-pass, light denoise, loudness normalised, looped with natural gaps and a cross-fade seam, 32 kHz mono Vorbis). CC BY-SA files must stay attributed and shared alike; the pack is distributed under CC BY-SA 4.0.
