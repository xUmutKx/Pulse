## Pulse 0.10.186

An all-in-one Android toolbox that dresses up as Windows 95 / XP / 7 / 10 / 11, Material or AMOLED. Android 12 or newer, arm64. Free and open source (GPL-3.0).

**Install:** download `Pulse-0.10.186.apk` below. Builds are signed with the fixed key in `ci/pulse.keystore`, so every new release installs over the last one. (If you have an older build signed with another key, uninstall it once first; back up with the in-app backup.)

### New in this release
- **Launcher**: in the Windows looks (95 / XP / 7 / 10 / 11) the apps list of 95, XP and 7 is an Explorer-style window, and Pulse's own pages (This PC, Recycle Bin, Paint, Task Manager, Control Panel, Performance, Services, Startup apps, Programs) open in framed windows with caption buttons; Pulse widgets come first in the widget picker.
- **Music player**: swipe up opens the lyrics (searching state, retry with another artist / title, fuzzy search, optional .lrc / MP3 tag saving), bold current line in the lyrics notification, smooth seek bar, shuffle / repeat menus, Poweramp widget redrawn, software equalizer when the system one cannot start, load a Poweramp backup (playlists, ratings, play counts, covers).
- **Screenshot / record tile**: tap for a screenshot through root (tries several ways for secure windows), long press for the recorder with show touches, floating pause / stop / pen / grab-frame bar.
- **Files**: selection bar pinned at the top with bigger buttons, pull down to refresh, open unknown types as archive / text / image / another app.
- **Tools**: network type fix for 3G / 2G, DNS and TTL, screen cover brightness and an open window with draggable edges, calculator keys per look.

### Notes
- Root and Shizuku are optional; most features work without them.
- It is a hobby project: expect rough edges and please report bugs.
