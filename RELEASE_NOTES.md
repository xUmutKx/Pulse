## Pulse 1.0.48

Changes since 1.0.30: Files: "Open archive" opens the full-page archive view, an "Open as" dialog in the Material style, swipe actions on the File types list (delete, open or select, per direction) instead of a trash button; Material dialogs use plain text buttons, Material buttons are tonal, and the remaining direct dialogs go through the same theme code; Toolkit: Floating keys (a button over every app, a mini keyboard with Esc, Tab, Ctrl and F keys; needs root or Shizuku); keyboard: translation bar, effects (colour wash, key colour, key motion, touch sounds), element symbols and many more accents on long press, optional compact bottom row with Shift, separate top and bottom brightness, a clearer Shift key, symbol families above the search, recent emojis stay in place while the panel is open, pop-ups no longer cut off on the number row, deleting the space behind a word reopens it, more careful typo learning, 131 typos built in.

**Which file:** `Pulse-1.0.48.apk` is for Android 12 and newer. `Pulse-1.0.48-android5.apk` is the build for older phones (Android 5 and newer, "low API"). Both hold the arm64-v8a, armeabi-v7a and x86_64 libraries. Builds are signed with the fixed key in `ci/pulse.keystore`, so every release installs over the last one. Both builds were compiled in CI; neither has been tested on every phone, so please report bugs.
