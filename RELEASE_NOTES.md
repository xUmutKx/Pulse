## Pulse 0.10.166

An all-in-one Android toolbox that dresses up as Windows 95 / XP / 7 / 10 / 11, Material or AMOLED. Android 12 or newer, arm64. Free and open source (GPL-3.0).

**Install:** download `Pulse-0.10.166.apk` below. Builds are signed with the fixed key in `ci/pulse.keystore`, so every new release installs over the last one. (If you have an older build signed with another key, uninstall it once first; back up with the in-app backup.)

### New in this release
- **Music player**: artist shown everywhere, a richer Material mini player (shuffle, repeat, round play button), lyrics kept on the cover with highlighted search words, a one-time lyrics index, an optional separate lyrics notification, covers that no longer flash the wrong picture while swiping, an equalizer that reports why it cannot start.
- **Widgets**: edge-to-edge Winamp widgets with the original Winamp 2.91 skin, music widget settings sheet (theme, cover size and side, text size, controls, accent, opacity, shape), working from a cold start.
- **Calculator** app (Windows 11 / 10 / classic looks), **network type** tool and Quick Settings tile (5G only, LTE, auto; needs root), screen cover clock styles and positions.
- **Office**: the 365 window is dark grey with white text in every look; Notepad-style text editor with an AMOLED black option; the installer streams APKs, installs zips with several apps one by one.
- **Files**: zip files from other apps open in Pulse, the storage scan is kept between runs, `/data/data` opens without lag, Storage by type opens files.
- **Windows 11 look**: icon style per group (Original, Fluent colour, Line), see-through pages, per-app places in Settings > Apps.

### Notes
- Root and Shizuku are optional; most features work without them.
- It is a hobby project: expect rough edges and please report bugs.
