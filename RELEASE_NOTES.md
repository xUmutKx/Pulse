**Which file:** `Pulse-1.0.143.apk` is for Android 12 and newer. `Pulse-1.0.143-android5.apk` is the build for older phones (Android 5 and newer, "low API"). Both hold the arm64-v8a, armeabi-v7a and x86_64 libraries. Builds are signed with the fixed key in `ci/pulse.keystore`, so every release installs over the last one. Both builds were compiled in CI; neither has been tested on every phone, so please report bugs.
