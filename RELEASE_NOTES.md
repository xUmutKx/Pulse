## Pulse 1.0.123

Changes since 1.0.105: videos open in the Pulse player from Files; holding backspace deletes word by word with a tick; the keyboard returns to the plain keys after it was closed on the emoji page; BlackOut module status explains itself; covers can be written into mp3 files safely (rehearsal on a copy, backup, check); the keyboard remembers names with their capital and offers the next name after one; more weather sources (MET Norway, OpenWeatherMap with your key); Island card tighter with more detail; BlackOut multi-select colours; keyboard screenshot slot works again on Android 11+, arrow keys move the cursor without the system highlight; floating keys button with a Material icon; notes tools behind one plus button; cover search runs in the background with progress; launcher wallpaper pairs on rotation; install buttons are rounded squares; Files rows closer together; automatic daily backup of the app and, separately, the keyboard (Download/Pulse backup) and a fuller backup; Emoji Kitchen removed; keyboard three-dot button at the right; weather: MGM counts in the combined forecast, real error text, city search fallback; Notes sketch page follows the look; lyrics card can use the cover photo; the top-right menu has no coloured 95/XP/7 icons; backspace hold deletes letters; the arrow keys and the Enter key no longer stay whitish after a touch; keyboard emoji skin tones (hold an emoji), Emoji Kitchen "Blend" draws one face from the key points of both emojis, keyboard settings show what the keyboard stores and can delete mixed pictures and the clipboard; Notes: the top right is New note and Settings only (sort, grid, trash moved into Settings), New note opens a blank note, Select all, the sketch bar follows the look. Changes since 1.0.98: the BlackOut and Palette pages are the full pages of the two apps (Palette: Studio, Preview, Apps, Apply, Settings, widgets, live wallpaper; BlackOut: setup guide, per-app pages, colour rules, Material You greys, Samsung Notes); the Island (a pill over the camera for the song, notifications, charger, headset, volume, torch, removed apps, screenshots); the emoji key is back beside ?123; lyrics share is one card with five cover colours, black and white; Canvas (a video per song); calendar month styles; weather add-a-place page; calculator Back and x²; Files: swipe actions in settings, back from a type list goes home, search at the top right, zip rows without cut/copy and with sizes, archives open in the browser, several APKs install as one Multi install; keyboard: faster suggestions, a retyped word is learned, a new screenshot waits in the right slot of the bar; Files recents and options in their own file so the theme of Pulse is not overwritten.

**Which file:** `Pulse-1.0.123.apk` is for Android 12 and newer. `Pulse-1.0.123-android5.apk` is the build for older phones (Android 5 and newer, "low API"). Both hold the arm64-v8a, armeabi-v7a and x86_64 libraries. Builds are signed with the fixed key in `ci/pulse.keystore`, so every release installs over the last one. Both builds were compiled in CI; neither has been tested on every phone, so please report bugs.
