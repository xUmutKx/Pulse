## Pulse 1.0.110

Changes since 1.0.105: the arrow keys and the Enter key no longer stay whitish after a touch; keyboard emoji skin tones (hold an emoji), Emoji Kitchen "Blend" draws one face from the key points of both emojis, keyboard settings show what the keyboard stores and can delete mixed pictures and the clipboard; Notes: the top right is New note and Settings only (sort, grid, trash moved into Settings), New note opens a blank note, Select all, the sketch bar follows the look. Changes since 1.0.98: the BlackOut and Palette pages are the full pages of the two apps (Palette: Studio, Preview, Apps, Apply, Settings, widgets, live wallpaper; BlackOut: setup guide, per-app pages, colour rules, Material You greys, Samsung Notes); the Island (a pill over the camera for the song, notifications, charger, headset, volume, torch, removed apps, screenshots); the emoji key is back beside ?123; lyrics share is one card with five cover colours, black and white; Canvas (a video per song); calendar month styles; weather add-a-place page; calculator Back and x²; Files: swipe actions in settings, back from a type list goes home, search at the top right, zip rows without cut/copy and with sizes, archives open in the browser, several APKs install as one Multi install; keyboard: faster suggestions, a retyped word is learned, a new screenshot waits in the right slot of the bar; Files recents and options in their own file so the theme of Pulse is not overwritten.

**Which file:** `Pulse-1.0.110.apk` is for Android 12 and newer. `Pulse-1.0.110-android5.apk` is the build for older phones (Android 5 and newer, "low API"). Both hold the arm64-v8a, armeabi-v7a and x86_64 libraries. Builds are signed with the fixed key in `ci/pulse.keystore`, so every release installs over the last one. Both builds were compiled in CI; neither has been tested on every phone, so please report bugs.
